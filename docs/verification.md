# Bootstrap verification

Verified locally on 2026-11-21 (America/Denver), macOS arm64.

Environment: Go 1.27.3 running a Go 1.24 module; Bubble Tea 1.3.10; FFmpeg 9.0.2; mpv 0.42.0; just 1.59.0. No media binaries are bundled.

## Results

| Check | Result |
|---|---|
| `just check` | Passed formatting, `go vet`, race-enabled unit tests, and build |
| `just test-integration` | Passed real FFprobe/FFmpeg decoding and mpv load/play/pause/seek/reset/error/cleanup tests |
| `just test-tui` | Passed real PTY sessions for video, image, GIF, audio, corrupt media, filtering, and mixed queues |
| `just build-all` | Compiled macOS/Linux arm64/amd64 with CGO disabled; Linux binaries not executed |
| `just doctor` | Found ffmpeg, ffprobe, and mpv |

Synthetic fixtures: 160 x 96 PNG; three-second animated GIF; eight-second MPEG-4/AAC MP4 with a sine tone; eight-second PCM WAV with title/artist tags; corrupt PNG. Fixtures are generated by `scripts/fixtures.sh`; no personal media is used.

The PTY harness sets `TERM=xterm-256color` and `COLORTERM=truecolor`, starts at 110 x 30, and exercises 70 x 20 resizing. It confirms color-cell output, advancing media time, paused seeking in both directions, stop/reset/resume, help, silent browsing during audio playback, filtering, image → GIF → video queue advancement, paused next-item navigation, and error visibility. It checks alternate-screen exit, restored terminal attributes (normalizing macOS's kernel-managed PENDIN flag), and disappearance of child processes. Raw transcripts are generated under `tmp/acceptance/` and intentionally ignored by git.

## Limits of the evidence

The harness is a real pseudo-terminal, not a named graphical terminal emulator. It verifies terminal I/O and state transitions, not how every emulator displays the cells. mpv tests use its null audio output; speaker output and perceptual audio/video synchronization were not audited. The renderer targets 12 fps, but no sustained frame-rate or CPU benchmark is claimed. Kitty graphics, tmux, SSH audio forwarding, Windows, subtitles, and a codec matrix beyond the listed fixtures remain unverified or unimplemented.

The bootstrap proof established that separate frame decoding can coexist with live TUI controls, seeking, resizing, and clean shutdown. Native-resolution graphics were added in the follow-ups below; a more efficient shared decoder remains future work.

## Usability and JPEG follow-up

A user screenshot exposed a real JPEG failure that PNG-only still fixtures missed: FFmpeg input seeking at `-ss 0` returned no frames for a JPEG. Still images now decode without seeking, even when their slideshow clock is nonzero. Single-frame decode has a ten-second timeout, and a failure replaces loading text with an explicit preview error.

Added JPEG regression cases at zero and nonzero slideshow times, odd preview widths, visible parent navigation, selection restoration, full-color layout bounds, error-state rendering, timeline keyboard/mouse seeking, and a live PTY JPEG preview. The full-color view was also rendered from an actual PTY transcript and visually inspected, revealing and correcting a truncated parent label and low-contrast pane titles. Artifacts remain in ignored `tmp/acceptance/`.

## Native images and search follow-up

Added a 1200 x 800 JPEG fixture and verified that its native PNG payload retains those dimensions. Protocol tests check lossless chunk reconstruction, bounded chunk size, upload reuse, placement coordinates, overlay clearing, and alternate-screen cleanup. The PTY suite explicitly exercises both the cell renderer and native upload/placement, including help and resize. Native terminal pixel rendering itself has not been visually verified in a graphical terminal.

Folder layout tests ensure that empty preview space is reclaimed, long-name browsing remains available via `B`, and cached fuzzy filtering works without another directory read. PTY checks exercise Ctrl+F search and opening a matched folder. Existing playback, JPEG, mouse/timeline, race, and cleanup checks remain in the suite.

Spectrum tests distinguish silence and tones from 20 Hz through 19.9 kHz, including frequencies between band centers. A real FFmpeg stream retains a 16 kHz tone and verifies overlapping-window timestamps and cancellation. UI tests cover aligned frequency labels, treble retention in narrow previews, and paused/stopped behavior. The PTY audio session checks that real spectrum bars and both hearing-range endpoints appear during playback. Null audio output remains the automated playback device.

## Native moving playback

Added a 1280 × 720 video fixture and verified that native PNG frames retain its dimensions and advance timestamps. Compositor tests ensure changed graphics are flushed without requiring a text redraw. The native-video PTY session checks repeated uploads, absence of cell pixels, play/pause, seek, stop, and cleanup. This verifies the transport and protocol; it does not substitute for visual inspection in the user's terminal.

## Capability detection and adjustable seeking

Auto mode now tests Kitty support at startup, with a 350 ms timeout and explicit renderer overrides. Protocol parser tests preserve unrelated keys/replies and cover rejection, cancellation, and timeout. The PTY suite exercises an unknown client with a fragmented positive response and simultaneous search input, a negative response despite a Ghostty environment hint, and no response. It verifies native output only after success, cell fallback otherwise, and terminal/process restoration in each case. Preview titles label the renderer. These checks emulate capability replies; they do not establish support in Termius or another named client.

Seek-step tests cover fractional durations, forward/backward movement, pause preservation, timeline arrows, cycle wrap, range clamping, and search-input isolation. The PTY suite starts with `--seek-step=1s`, checks the displayed labels and actual video position, changes to 5 seconds with `,`, and seeks back with the timeline. A zero-duration CLI value is rejected. The fixed 30-second shortcuts are unchanged.

## Document preview foundation

`just check`, `just test-integration`, `just test-tui`, `just test-documents`, and `just build-all` passed for the document slice. New cases cover Markdown tables/reference images, source layout, binary/invalid UTF-8 detection, a nonblocking FIFO path, bounded UTF-8 truncation, cancelled reads, terminal escape injection through both raw bytes and Markdown entities, document focus/scroll/source/resize, stale generations, and media queue isolation. The PTY suite also pauses/seeks audio while a README stays visible. A document-view transcript was rendered offline and inspected for layout and styling. This does not verify a graphical terminal's native pixels.

## Embedded images and GIF replay coverage

The embedded-image slice passed `just check`, backend integration tests, and the baseline, document, and GIF replay PTY scripts. Unit tests cover local URL resolution, PNG bounds/transparency, multiple native placements, crop updates without retransmission, overlay/exit cleanup, stale results, visible failures and stable geometry after offscreen pixel eviction. The document harness checks two simultaneous local images, reference-style Markdown, source toggling, scrolling/resizing, and missing/remote image fallbacks.

`just test-gif-replay` exercises replay via Space and Enter after EOF and opening a GIF in another folder, in cells and native modes. Native assertions decode transmitted PNG payloads and require changing frames after each replay/switch. The user's two reported GIFs also completed and replayed in a separate PTY investigation. These checks did **not** reproduce the reported stuck/blank state, and do not establish correct pixels in the user's terminal emulator. The reported GIF bug remains unresolved pending the distinction between a frozen transport and a blank rendering surface.


## Optional native Mermaid

With mmdg v0.13.0 available on the test PATH, `just test-mermaid` passed real flowchart/sequence rendering and PTY checks for fenced and standalone diagrams, source toggling, resizing, overlay restoration, invalid syntax, missing-helper fallback, and cell-only source display. PNGs extracted from the actual PTY protocol were visually inspected: labels, connections and dark backgrounds are readable. This verifies the generated images, not their placement in a graphical terminal emulator.

Unit/race tests cover renderer cancellation, bounded source/output, malformed PNGs, cache reuse/eviction, replaceable fence layout, and preservation of source on failure. `just check`, `just test-integration`, `just test-tui`, and `just build-all` passed. Peep's four cross-build targets compiled with CGO disabled; the optional helper was executed on this macOS host only. No Node/browser runtime was installed, and the helper remains in ignored `tmp/tools` for testing rather than the user's global PATH.

## Sustained illustrated-document scrolling

`document-scroll-smoke.py` holds `j` and Down through the Night Shift guide via
its symlink, in both cell and Kitty modes. Each session must reach the bottom
without a backward offset jump as images and diagrams finish loading. Unit cases
also preserve content when an asset above the viewport grows, preserve an exact
position inside an image on reload, and keep later image completion from moving
the viewport. The original implementation repeatedly jumped from around row 28
to row 8 in the same PTY reproduction.
